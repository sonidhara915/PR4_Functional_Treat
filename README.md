# 📊 Data Analyzer and Transformer Program

> A Python-based menu-driven application for data analysis, transformation, and statistical operations.

---

## 🌟 Project Description

The **Data Analyzer and Transformer Program** is an interactive Python application that allows users to input datasets and perform various analytical operations. The project demonstrates fundamental Python concepts such as functions, recursion, lambda expressions, sorting, filtering, and statistical analysis.

This project is ideal for beginners who want to practice Python programming while working with real-world data operations.

---

## ✨ Key Features

### 📥 Data Input
- Store data in **1D Array** format.
- Store data in **2D Array** format.
- Save datasets for further processing.

### 📈 Data Summary
Generate quick insights from the dataset:
- Total Elements
- Minimum Value
- Maximum Value
- Sum of Values
- Average Value

### 🔄 Factorial Calculation
- Calculate factorials using **Recursion**.
- Demonstrates recursive function implementation.

### 🎯 Data Filtering
- Filter values based on a threshold.
- Uses **Lambda Functions** and `filter()`.

### 🔢 Data Sorting
Sort data in:
- Ascending Order ⬆️
- Descending Order ⬇️

### 📊 Dataset Statistics
Display:
- Minimum Value
- Maximum Value
- Sum of Values
- Average Value

Implemented using:
- `*args`
- `**kwargs`
- Multiple Return Values

### 🚪 Exit Program
Safely close the application with a user-friendly message.
